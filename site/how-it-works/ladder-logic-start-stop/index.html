How a Start Stop Latch Works in Ladder Logic

Choose whether the stop button is wired normally closed or normally open and set the PLC scan time. Watch the demo press Start and Stop, then break the stop wire and see which wiring stops the motor safely.

Live animationAdjustable slidersFormula and example

Quick answer: A start stop latch uses the output's own contact in parallel with the Start button, so the coil stays on after Start is released. A normally closed Stop button in series breaks the rung and drops the latch.

What Is a Start Stop Latch in Ladder Logic?

The start stop circuit with a seal in contact is the first program almost every PLC engineer writes. It copies the classic hard wired motor starter, where an auxiliary contact of the contactor holds its own coil.

In ladder logic the Start contact and a contact of the output coil sit in parallel branches, and the Stop and overload contacts sit in series after them. One rung gives a memory that survives the release of the Start button.

The detail that matters in the field is how the Stop button is wired. A normally closed stop button makes a broken wire act like a stop command, which is why it is the standard practice.

Start Stop Latch in Ladder Logic Working Principle Step by Step

  1. At rest the Stop and overload contacts are closed and the Start contact is open, so no power reaches the coil Q0.0.
  2. Pressing Start closes I0.0; the rung becomes true, Q0.0 turns on and the contactor starts the motor.
  3. In the same moment the seal in contact Q0.0 in the parallel branch closes, so the rung stays true after Start is released.
  4. Pressing Stop opens the NC field contact, the input I0.1 goes to 0 and the series contact breaks the rung; Q0.0 and its seal in contact drop out.
  5. A broken stop wire or a tripped overload also removes the input signal, so the motor stops instead of running out of control.

Start Stop Latch in Ladder Logic Formula

Q0.0 = (Start I0.0 OR Q0.0) AND Stop I0.1 AND Overload I0.2
Stop and overload are wired NC in the field and examined as closed in the program, so a 1 means healthy
Press Start: (1 OR 0) AND 1 AND 1 = 1; release Start: (0 OR 1) AND 1 AND 1 = 1, the latch holds
Press Stop: (0 OR 1) AND 0 AND 1 = 0, the latch drops
Example: NC stop button and 10 ms scan: the output reacts within about 2 × 10 = 20 ms, plus input filter and contactor time

Where a Start Stop Latch in Ladder Logic Is Used

Motor startersPumps, fans, conveyors and agitators started and stopped from a local station.
Process sequencesHolding a step active after a momentary command.
Alarm acknowledgeLatching an alarm until an operator resets it.
Training and testingThe first rung used to learn contacts, coils and the scan cycle.

Advantages

  • Simple logic that every technician can read
  • Copies the familiar hard wired starter
  • Fail safe when Stop and overload are wired NC

Limitations

  • The latch is lost on PLC power cycle unless a retentive bit is used
  • A Stop wired NO will not stop the motor if its wire breaks
  • Not a substitute for a hard wired emergency stop and safety relay

Start Stop Latch in Ladder Logic Field Tips and Common Problems

  • Wire Stop and overload contacts NC and examine them as closed in the program.
  • Keep emergency stop in a hard wired safety circuit that removes power to the contactor, not only in PLC logic.
  • Use the contactor auxiliary contact as a run feedback input to detect a contactor that did not pull in.
  • Check the input LED on the card first: if Stop LED is off while nobody presses it, look for a broken wire or loose terminal.

Frequently Asked Questions

Why is the stop button wired normally closed?

With an NC stop button the input is 1 when healthy. A broken wire or loose terminal makes it 0, which the program treats as a stop, so the fault is safe.

What is a seal in contact?

It is a contact of the output coil placed in parallel with the Start button. Once the output is on, this contact keeps the rung true after Start is released.

Can I use set and reset instructions instead?

Yes, set and reset coils give the same latch. Many engineers prefer the seal in rung because all conditions are visible on one line.

What happens if Start and Stop are pressed together?

In this rung Stop is in series after the branch, so Stop wins and the motor stays off. This stop dominant behaviour is the safe choice.
