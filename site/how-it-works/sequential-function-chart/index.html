How a Sequential Function Chart Works

Set the fill, mix and drain times with the sliders. Watch the active step token move down the chart each time a transition condition becomes true, and see the tank follow the actions.

Live animationAdjustable slidersFormula and example

Quick answer: A sequential function chart (SFC) splits a machine or batch process into steps joined by transitions. Only the active step runs its actions, and the chart moves to the next step when the transition condition below it becomes true.

What Is a Sequential Function Chart (SFC)?

SFC is one of the five PLC languages defined in IEC 61131 3, and it is based on the GRAFCET method of IEC 60848. It is drawn like a flowchart, but it has strict rules about which step is active and when it changes.

Each step holds actions such as open a valve or start a motor, and each transition holds a Boolean condition such as a level switch or a timer. The step before a transition must be active and the condition must be true before the chart can move on.

This makes sequences easy to read, test and troubleshoot, because the active step tells you exactly where the machine is waiting. Batch reactors, filling machines, CIP systems and start up sequences are common uses.

Sequential Function Chart (SFC) Working Principle Step by Step

  1. At start up the initial step 0 is active and the chart waits for the Start command.
  2. When Start is true, transition 0 fires: step 0 is deactivated and step 1 Fill becomes active, opening inlet valve XV1.
  3. When the high level switch LSH closes, the chart moves to step 2 Mix; the agitator runs and the step timer counts.
  4. When the step elapsed time reaches the mix time, step 3 Drain opens XV2 until the low level switch LSL shows the tank is empty.
  5. The last transition jumps back to the initial step, so the sequence is ready for the next batch.

Sequential Function Chart (SFC) Formula

Batch cycle time = wait for Start + fill time + mix time + drain time
Batches per hour = 3600 ÷ batch cycle time (s)
A transition fires only when the step above it is active and its condition is true
Mix transition condition: Mix.T ≥ mix time, where .T is the step elapsed time
Example: 2 s wait + 8 s fill + 10 s mix + 6 s drain = 26 s, so 3600 ÷ 26 = 138.5 batches per hour

Main Parts of a Sequential Function Chart (SFC)

PartWhat it does
StepA state of the sequence; it is either active or inactive, and the initial step is drawn as a double box
TransitionA horizontal bar with a Boolean condition that moves the chart from one step to the next
Action blockTells what a step does, with a qualifier such as N (while active), S (set), R (reset), L (time limited) or P (pulse)
Step flags and timersEach step has an active flag .X and an elapsed time .T that logic and transitions can use
Divergence and convergenceA single line branch selects one path; a double line branch runs parallel paths at the same time

Where a Sequential Function Chart (SFC) Is Used

Batch processesFill, heat, react, mix and discharge phases of a reactor or blending tank.
Packaging and filling machinesIndex, fill, cap and eject steps that repeat for every product.
Clean in placeRinse, caustic wash, rinse and acid wash phases with timers and temperature checks.
Equipment start upOrdered start of pumps, fans and valves with permissives checked at each step.

Advantages

  • The active step shows at a glance where a sequence is waiting
  • Each step and transition can be tested on its own
  • Parallel and alternative branches are drawn clearly

Limitations

  • Less suited to continuous control loops, which are better in function blocks
  • Large charts need careful naming and layout to stay readable
  • Mixing set and reset actions across steps can leave outputs on unexpectedly

Sequential Function Chart (SFC) Field Tips and Common Problems

  • When a sequence stops, look at the active step and then check only the transition condition directly below it.
  • Prefer N qualifiers for outputs so they switch off automatically when the step ends; use S and R only with a clear reset step.
  • Add a step time limit alarm using .T so a valve that never reaches its limit switch raises a fault instead of waiting forever.
  • Keep interlocks and emergency stops outside the SFC in plain logic so they act in every step.

Frequently Asked Questions

Is SFC a real PLC language?

Yes. IEC 61131 3 defines SFC together with ladder diagram, function block diagram, structured text and instruction list. The actions and transitions inside an SFC are written in one of the other languages.

What is the difference between SFC and GRAFCET?

GRAFCET, standardised in IEC 60848, is the design method for describing sequences. SFC is the PLC programming language built on the same idea of steps and transitions.

Can two steps be active at the same time?

Yes, after a simultaneous divergence drawn with a double line. Both branches run in parallel and meet again at a double line convergence, which waits for all branches.

What does the N qualifier mean?

N means non stored: the action is on only while the step is active. When the chart leaves the step, the action switches off.
